# Geiger Counter

<ItemImage id="cyberfarm:geiger_counter" scale="2" float="left" />

The Geiger Counter measures [radiation](radiation.md). Carry it to know when a place is safe and
when to put on a [Hazmat Suit](hazmat_suit.md).

<br clear="all" />

## Using it

- Hold it in **either hand**.
- It **clicks** faster the more radiation there is.
- It shows the level in **Rad** above the hotbar.
- A [Muffler](muffler.md) never silences it.

| Reading | Color | Meaning |
| --- | --- | --- |
| below 20 Rad | green | *Safe* |
| 20 Rad and more | orange | *Radiation sickness* |
| 100 Rad and more | red | *DANGER* |

The Neural Chip's **Geiger HUD** program shows the same reading without a counter in hand: see
[Trinkets](trinkets.md).
