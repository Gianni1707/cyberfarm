# Drone Engineer's Handbook

<ItemImage id="cyberfarm:drone" scale="2" float="left" />

Welcome, engineer! **CyberFarm** lets you build modular drones that run your farms for you.
You assemble a drone from a **frame**, one or more **function modules** and optional **addons**, give it a
**Drone Dock** to live on, and it does the work while you do something more fun.

Drones and machines run on **FE** (Forge Energy), so they work with power from any other tech mod.

Using **JEI** or **REI**? Look up the Drone Assembler to see what each frame tier can hold, and
use the info page (the "i" tab) of any CyberFarm machine for a quick explanation.
