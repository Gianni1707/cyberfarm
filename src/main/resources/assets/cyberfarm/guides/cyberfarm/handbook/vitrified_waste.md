# Vitrified Waste

<BlockImage id="cyberfarm:vitrified_waste" scale="3" float="left" />

Vitrified Waste is nuclear waste made safe: inert green glass. It does **not** contaminate, so you
can store it anywhere or build with it.

<br clear="all" />

- **Get it**: the [Waste Reprocessor](waste_reprocessor.md) turns every Depleted Fuel Rod into one
  block.
- **Mine it** with a pickaxe; it drops itself.
- It glows very faintly.
